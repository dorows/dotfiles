When given the task to add a feature in this directory you need to create a folder with the feature's name and another folder called source inside it and a instructions.md. The source will contain the most amount of code you can give and the instructions.md will explain what the user intent was while making this feature with the instructions on where each code snippet goes and how to implement it. Keep the instructions as brief as possible.

Share code inside source folder when the feature is big, when it's small snippets inside the instructions work. Be the judge of that, the AI implementing this needs the build a feature as similar as possible with your instructions.

The name of the feature's file needs to be indistinguishable and clear.

When prompted to commit and push do not add a Co-author by codex anywhere.
